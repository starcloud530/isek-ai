# 游玩形式：文字游戏

一章是一场戏，不是一页网文，也不是开场一句问候的角色聊天。画面像文字游戏：一张静止的 CG 铺满屏幕，人物按台词依次走到前面说话，用户在最底下插一句，戏就往下走。

组件是固定的，皮肤可以换。对话框、名字、输入条用代码画，不做成图片，这样字能变长，样式也能换。真正生成的图只有背景 CG 和立绘。

## 一屏上有什么

1. 背景 CG。铺满屏幕，同一镜头里不动。沉浸感来自这张图，不来自聊天记录。
2. 当前说话人的立绘。同一张立绘反复用，不按每一句重画。
3. 表情和特效层。嘴和眉用 Live2D 跟着语气动，生气符号这类效果叠在立绘上，背景不动。
4. 名字。只有角色说话时才出现。
5. 对话框。一屏一句。
6. 底部输入条。用户打一句，或点一个选项，这一章就继续。
7. 章节进度。一小条，标出走到哪。

## 两种句子

角色说话时，立绘亮起来，名字挂在对话框上，字是这一句台词。

旁白推进剧情时，画面上没有人。立绘退到边上或淡掉，只留 CG。一条更淡的字，没有头像，也没有名字，放在画面中部或偏下。

用户插话也是这一章里的一句，不是另开一个聊天室。选「推门」或自己打一行，效果一样，都是把这场戏往下接。本章说和下一章，要等这场戏结束才出现。

## 创作者要填的

播放器先定，工具后做。能播出来的字段，就是创作者要填的：背景、出场人物、这一句是谁说的还是旁白、台词、表情、特效。上架就是把这些字段按顺序播出来。
