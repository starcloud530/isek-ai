# 游玩形式：直播间

手机上的一章，用直播间来放。不是抖音那种半透明弹幕叠在画面上。画面和互动分成两块实区，对半切，中间一条硬边。

## 上半：放映

顶上一条很窄的栏：左边返回，中间是故事标题。

栏下面整块是这一镜头的画面。一张静止 CG 铺满，当前说话的人在这张图里。名字不挂在画面上，跟到下面的评论里。

## 下半：评论区

一块不透明的列表，像直播间评论，不是大头像卡片。每一行一个人：很小的圆头像，大约一行字那么高，旁边是名字和这一句台词。角色轮流出现，用户打的那句也进同一条列表。

最底下单独一条输入框，钉住，不跟评论滚走。

## 和文字游戏的关系

播的还是同一场戏：背景、谁在说、台词、旁白。换的是手机上的皮。旁白也是评论区里的一行，没有头像，没有名字，字更淡。本章说和下一章，等这场戏结束再出现。
